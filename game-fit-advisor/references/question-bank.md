# 题库与判定口径

两个模块共 16 个维度。**不要照抄提问**：保留判定意图，用用户的语言和当前对话上下文改写成自然问句。每题都必须是可回答的具体情境，禁止抽象术语堆叠。

维度 key 供 `scripts/diagnose.py` 使用。

---

## 模块一：快速玩法诊断（8 题）

聚焦直接影响体验的要素：玩法、操作、节奏、社交、挑战、内容消耗、沉浸感、时间投入。

### 1. 核心玩法类型 · `core_loop`

**问**：这款游戏的核心玩法是动作战斗、策略解谜、开放探索、模拟经营，还是其他？你平时最常玩、最容易上头的是哪一类？

**判定线索**

| 回答 | 判定 |
|---|---|
| 玩法类型与游戏一致，且是他熟悉/常玩的类型 | 匹配 |
| 类型相近（如都属动作类但一个偏硬核一个偏割草），或他只玩过零星同类 | 部分匹配 |
| 明确说"这类我玩不下去 / 上手就困" | 冲突 |

**追问**：你上一款玩超过 30 小时的游戏是什么？它和这款的相似点在哪？

### 2. 操作难度 · `controls`

**问**：这款游戏需要精准操作吗——比如快速反应、复杂按键组合、卡帧闪避？你有类似游戏经验吗？如果手速偏慢，打到卡关会不会觉得挫败？

**判定线索**

| 回答 | 判定 |
|---|---|
| 有同类操作经验，且把失败视为学习过程 | 匹配 |
| 没经验但愿意练；或有经验但自认手速一般 | 部分匹配 |
| 明确说"反应慢 / 手残会让我烦躁到弃坑" | 冲突 |

**追问**：若同一场 BOSS 战连续失败 3 次，你会感到激励还是烦躁？

### 3. 游戏节奏 · `pace`

**问**：游戏是节奏紧凑（竞技类需持续专注、不能暂停），还是节奏悠闲（种田、建造类可随时暂停、随时退出）？你更适应哪一种？

**判定线索**

| 回答 | 判定 |
|---|---|
| 游戏节奏与他的作息/注意力习惯一致 | 匹配 |
| 能接受但要挑时间段玩（如只周末打竞技） | 部分匹配 |
| 需要他在无法专注的时段玩，或他要求随时能暂停 | 冲突 |

**追问**：你通常什么时段玩？中间被打断（家人、消息、外卖）的频率高吗？

### 4. 社交需求 · `social`

**问**：这款游戏必须组队或联机才能推进，还是可以全程单机？遇到坑队友、被指挥、或者公屏对喷，你能接受吗？

**判定线索**

| 回答 | 判定 |
|---|---|
| 游戏形态与他期望的社交强度一致 | 匹配 |
| 单机能推进但组队收益更高，他愿意偶尔联机 | 部分匹配 |
| 他明确要单机，而游戏核心内容强绑联机 | 冲突 |

**追问**：你能接受和陌生人固定时间约着打本吗？还是更想自己随时上线随时下线？

### 5. 挑战类型 · `challenge`

**问**：游戏的核心挑战来自技巧（BOSS 战、操作上限）、策略（资源管理、阵容搭配），还是运气（抽卡、随机掉落）？你更享受哪一种？

**判定线索**

| 回答 | 判定 |
|---|---|
| 主挑战类型正中他的偏好 | 匹配 |
| 主挑战可接受，但次要挑战是他讨厌的（如讨厌抽卡但有保底） | 部分匹配 |
| 主挑战就是他最排斥的（如讨厌随机性但游戏核心是抽卡） | 冲突 |

**追问**：如果卡关 2 小时只能靠"多试几次碰运气"过关，你会继续还是关掉？

### 6. 内容消耗 · `content`

**问**：这款游戏是剧情驱动、一次性通关，还是长期刷副本、养成角色的"肝"型？你能接受重复刷同一关卡吗？

**判定线索**

| 回答 | 判定 |
|---|---|
| 游戏内容形态与他的消费习惯一致（含"就爱刷"） | 匹配 |
| 能接受有限重复（如每周固定几次），不接受无上限 | 部分匹配 |
| 只玩一次性剧情，且明确排斥重复内容 | 冲突 |

**追问**：连续一周每天刷同样的日常任务，第几天你会开始烦？

### 7. 沉浸感来源 · `immersion`

**问**：你更看重精美画面和剧情代入，还是刺激的战斗反馈、策略成就感？这款游戏的主打卖点在哪一边？

**判定线索**

| 回答 | 判定 |
|---|---|
| 他在意的卖点正是游戏强项 | 匹配 |
| 游戏强项他不反感但非最爱；或他要的那部分游戏只是"够用" | 部分匹配 |
| 他在意的部分恰好是游戏公认短板 | 冲突 |

**追问**：如果剧情平庸但战斗手感一流，你还会玩下去吗？反过来呢？

### 8. 时间投入 · `time_budget`

**问**：游戏是否要求每天固定上线（公会任务、体力、限时活动）？你日常能稳定投入多少时间——是每天 30 分钟，还是周末能连打 5 小时？

**判定线索**

| 回答 | 判定 |
|---|---|
| 可投入时长 ≥ 游戏维持进度所需时长 | 匹配 |
| 工作日不足但有周末补；或游戏可"佛系玩"仅损失排名 | 部分匹配 |
| 明确每天只能 30 分钟以内，而游戏强制日常 ≥1 小时 | 冲突 |

**追问**：某周完全没上线，回来后进度落后一大截，你能接受吗？

## 模块二：深度全面分析（8 维度）

在模块一基础上增加时间、硬件、付费、社区、情感等深层因素。**若模块一已完成，本模块不再重复其 8 个维度**；用户若直接选模块二，则模块二这 8 维度即为全部诊断内容，需要时可顺带记录模块一的关键偏好。

### 1. 时间成本 · `time_cost`

**问**：游戏靠什么"绑定"你——每日任务、限时活动、体力回复、赛季通行证？如果某周因现实忙碌中断，进度会严重落后吗？落后了你还追得回来吗？

**判定线索**：可中断且能追回 → 匹配；落后可追但需集中补课 → 部分匹配；错过即永久损失关键奖励且他无法接受 → 冲突。

**追问**：出差/加班一周完全没上线，你能接受吗？

### 2. 硬件要求 · `hardware`

**问**：你打算用什么设备玩（PC / 主机 / 手机 / 云游戏）？这款游戏在该设备上的实际表现你查过吗？若需要升级配置，你愿意为它花钱吗？

**判定线索**：现有设备满足推荐配置 → 匹配；满足最低配置需降画质、或可用云游戏替代 → 部分匹配；不满足且不愿升级 → 冲突。

**追问**：如果只能 720p 低画质 30 帧运行，你会先玩着还是等换设备？

### 3. 付费模式 · `payment`

**问**：游戏是否"氪金变强"——抽卡、属性道具、战令？你能接受付费影响强度或排名，还是只接受纯外观内购？你预计每月能接受多少预算？

**判定线索**：买断/纯外观 → 匹配；有影响强度的付费但零氪可玩 → 部分匹配；核心体验明显依赖付费而他预算有限或强烈排斥 → 冲突。

**追问**：如果零氪每月落后主流玩家一个梯队，你还能玩得开心吗？

### 4. 社区氛围 · `community`

**问**：这款游戏的玩家群体氛围你了解过吗？如果频繁遇到恶意玩家、喷子、或者"必须看攻略否则没法玩"的环境，你的心态会受影响吗？

**判定线索**：氛围友好或他可完全隔绝社交 → 匹配；偶有负能量但他能无视 → 部分匹配；他容易被社区情绪影响且游戏社区以高压/戾气著称 → 冲突。

**追问**：被队友语音骂了一句，你接下来还会继续玩吗？

### 5. 更新频率 · `update`

**问**：游戏更新频繁吗——赛季制、资料片、还是长期稳定一个版本？你喜欢长期玩同一版本，还是热衷追新内容、怕"没新东西"？

**判定线索**：更新节奏与他的追新意愿一致 → 匹配；更新偏快需要持续学习、或偏慢他会腻 → 部分匹配；强制追新（不更新就掉队）而他无法持续跟进 → 冲突。

**追问**：每 3 个月一次大版本、旧装备作废，你接受吗？

### 6. 情感体验 · `emotion`

**问**：游戏基调是轻松治愈，还是暗黑压抑、高压紧张？你想从游戏里获得的是放松，还是史诗感、成就感、肾上腺素？

**判定线索**：基调与需求一致 → 匹配；基调他不排斥但也不是想要的 → 部分匹配；他只想放松而游戏以高压恐怖/竞技挫败为主 → 冲突。

**追问**：打完两小时，你希望的感觉是"放松了"还是"我变强了"？

### 7. 长线留存 · `retention`

**问**：游戏后期会不会出现"内容荒"或枯燥的重复劳动（日常、扫图、看广告）？你能接受"长草期"——几周没新内容、只能重复刷吗？

**判定线索**：长期有目标循环或他享受重复 → 匹配；有长草期但可淡出、随时回归 → 部分匹配；内容荒来得快且是他最反感的"上班感" → 冲突。

**追问**：连续 3 周只有日常任务可做，你会退坑还是照刷？

### 8. 价值观契合 · `values`

**问**：游戏是否涉及你介意或敏感的题材——暴力血腥、历史/文化争议、擦边内容、赌博式抽卡？这些会影响你的游玩意愿吗？家里/同住的人会在意吗？

**判定线索**：无敏感点或他无所谓 → 匹配；有争议题材但他可接受、只是不想公开玩 → 部分匹配；题材触及其底线或会带来现实压力 → 冲突（并且是**高优先级冲突**）。

**追问**：如果当着家人/室友的面玩会被说，你还会玩吗？

## 提问纪律

- **一题一问**：不要把判定表里的"线索"当问题抛给用户，只问加粗那句（可改写），用户答完由你判定。
- **禁止复读**：同一维度在同一场诊断中只正式问一次，追问上限一次。
- **禁止引导**：不加"这游戏很难的，你能接受吗"这类暗示性前缀。
- **术语落地**：出现"肝""氪""长草期""上手门槛"等词，同一句内必须给出具体解释或例子。
